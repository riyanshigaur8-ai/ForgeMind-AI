# ForgeMind AI

ForgeMind AI is a modern AI Career Operating System built using Google ADK.

The backend contains four specialized AI agents.

1. SkillLens
- Analyzes user skills
- Finds skill gaps
- Suggests technologies

2. ProjectScout
- Recommends portfolio projects

3. SprintPlanner
- Creates weekly implementation roadmaps

4. PortfolioForge
- Reviews GitHub, Resume and Portfolio

The frontend should feel like a premium SaaS application.
