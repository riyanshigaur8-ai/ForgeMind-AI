# ForgeMind AI

## 🚀 Multi-Agent Project Intelligence Platform

ForgeMind AI is a multi-agent system built using Google Agent Development Kit (ADK) and Gemini. It helps students and aspiring developers transform their skills into portfolio-ready projects through personalized guidance, project recommendations, roadmap generation, and career-focused mentoring.

---

## 📌 Problem Statement

Many students complete courses and tutorials but struggle to:

* Choose the right projects for their career goals
* Identify skill gaps
* Break projects into manageable milestones
* Build a strong portfolio
* Prepare for internships and placements

ForgeMind AI addresses these challenges using a team of specialized AI agents that collaborate to guide users from learning to building.

---

## 🎯 Vision

ForgeMind AI acts as a virtual project mentor team.

Instead of providing generic advice, it analyzes a user's skills, career goals, and project interests to generate personalized project recommendations, learning roadmaps, and portfolio guidance.

---

## 🏗️ Planned Multi-Agent Architecture

### SkillLens Agent

Analyzes user skills and identifies strengths, weaknesses, and learning gaps.

### ProjectScout Agent

Recommends portfolio-worthy projects based on skills and career goals.

### SprintPlanner Agent

Creates milestone-based project roadmaps and learning plans.

### PortfolioForge Agent

Generates resume bullet points, GitHub README content, and portfolio descriptions.
